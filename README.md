# ChanCam

48MP Apple ProRAW + LiDAR 깊이로 찍고, 직접 만든 Metal 파이프라인으로 현상하는 카메라.

- **촬영**: 48MP ProRAW(DNG) + LiDAR 깊이맵 + 인물 매트를 한 번에 저장. 셔터는 즉시 반응하고 현상은 백그라운드에서 진행률과 함께.
- **현상(전부 GPU)**: 애플 기본 보정을 모두 끈 선형 데이터에서 시작 → 휘도/색도 분리 노이즈 제거 → LiDAR 보케 → 로컬 톤 → 컬러 → 디테일 → 마무리.
- **보케**: 실제 얇은 렌즈 공식 `CoC = (f²/N)·|S2−S1| / (S2·(S1−f))`. 선형 HDR에서 디스크 게더링을 해서 밝은 점이 보케 볼로 피어난다. 조리개 날 수, 고양이눈, 구면수차(링 보케)까지.
- **기본 프로파일 `Chan`**: Sony a7 III + FE 50mm F1.8로 찍은 사진 171장의 Lightroom(XMP) 보정값 평균 — 하이라이트 −75, 섀도우 +55, 생동감 +12.

## 메모리 설계
48MP에서 풀해상도 버퍼는 두 개만 두고 번갈아 쓴다. 깊이·보케는 1/4, 로컬 톤 마스크는 1/8 해상도에서 계산하고 셰이더가 정규화 좌표로 샘플링해 업샘플한다.

## 저장 공간
ProRAW 원본은 한 장에 70~100MB다. 설정에서 "현상 후 원본 RAW 보관"을 끄면 결과 JPEG만 남긴다.

`-demo` 인수로 실행하면 카메라 없이 가짜 데이터로 화면을 보여준다 (CI 스크린샷용).
